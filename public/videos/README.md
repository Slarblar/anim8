## Video Specifications

For optimal performance:
- Format: MP4 (H.264 codec)
- Resolution: 1920x1080 or higher
- File size: < 10MB recommended for hero video
- Frame rate: 30fps or 60fps
- Length: 5-15 seconds for loops
